# Student Management System

A simple Java console application to manage student information.

## Features

* Add a new student
* Display all students
* Search for a student by ID
* Update student information
* Delete a student
* Exit the program

## Student Information

Each student has:

* ID
* Name
* Grade

## How to Run

1. Open the project in your Java IDE.
2. Run the `main` method.
3. Choose an option from the menu.
4. Follow the instructions on the screen.

## Menu

```text
1. Add Student
2. Display All Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit
```

## Technologies

* Java
* ArrayList
* Scanner

## Project Goal

The goal of this project is to practice Java basics, methods, loops, conditions, and `ArrayList`.
